# 📊 LeetMetric – LeetCode Stats Tracker

A simple web app to fetch and display LeetCode user statistics using a public REST API.

## 🚀 Features
- Search LeetCode user by username
- Difficulty-wise problem stats (Total /Easy / Medium / Hard)
- Circular progress visualization
- Clean dark UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- REST API

## 🌐 API Used
https://leetcode-stats-api.herokuapp.com/{username}

## ▶️ How to Run
Open `index.html` in browser and search a username.
